# NoobOS Architecture

## Status

This document describes the planned architecture of NoobOS.
Most details are subject to change.

## Goals

* Learn operating system development
* Understand low-level computer systems
* Build a functional hobby operating system

## Planned Architecture

| Component            | Choice     |
| -------------------- | ---------- |
| CPU Architecture     | x86_64     |
| Programming Language | C          |
| Bootloader           | GRUB 2     |
| Kernel Type          | Monolithic |
| Target Platform      | PC         |

## Notes

This document will evolve as the project develops.
